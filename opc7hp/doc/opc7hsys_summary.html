OPC7 FPGA system

A complete computer around the pipelined opc7hpcpu: boot ROM, main memory, a UART and GPIO, built for the Tang Nano 20K and, later, ECP5 boards. Phase 1 uses block RAM for main memory; caches and SDRAM follow.

Phase 1 so far

Built

  • opc7hsys.v: the board-independent system, with ROM, RAM, I/O decoding and GPIO.
  • opc7_uart.v: UART with FIFOs and a clock divider.
  • tn20k_sys.v: the Tang Nano top, with PLL, power-on reset and LEDs (LED 5 shows halted).
  • opc7sys_rom.s: the BCPL runtime's console routines rewritten to use the UART, so programs need no change.
  • sysrun.sh: builds a BCPL program for the system, simulates it, and compares the UART output with the expected text.
  • tn20k_build.sh: makes a Tang Nano bitstream for a program.

Checked

  • hello runs on the whole system in simulation: ROM, RAM and UART, with output matching the emulator.
  • All 60 claude-tests and bcpltests programs are being run through the system simulation. A simulation-only fix (RAM cleared to zero, as in block RAM) is being rechecked on the programs it affected.
  • The Tang Nano bitstream for hello builds and meets timing at 54 MHz.

Notes

  • Software layout unchanged. sial2opc already puts programs at 0x1000 and the runtime's MOS entry points below it, so the boot ROM covers exactly the runtime.
  • ROM per program in phase 1. Each build puts the program's low 4K words in the ROM and the rest in RAM. A fixed ROM with a loader comes in phase 4.
  • Halt. opc7hpcpu gained a hlt output so the system can stop the CPU at the end of a program. Without it, a finished program would return to address 0 and start again.
  • To check on the board. The UART pins (69 TX, 70 RX) and the reset buttons haven't been confirmed against the Tang Nano schematic yet.
